# docs/test-procedures/opamp

Owner: Connor (op-amp block).

Holds the op-amp block's **finalized test-circuit specification** and its
**deviations-from-standard** document.

- The executable schematic-capture spec currently lives with the hardware at
  [`hardware/blocks/opamp/EDU1_Opamp_Block_Spec_v4.md`](../../../hardware/blocks/opamp/EDU1_Opamp_Block_Spec_v4.md).
  A prose test-procedure doc (what to measure, instrument setup, pass/fail limits,
  data format) goes here once written.
- Deviations from MIL-STD-883 4001-series methods (fixture-by-fixture EDU1 adaptations)
  should be captured in a `deviations.md` here rather than scattered in the schematic
  notes.

See [`docs/standards/INDEX.md`](../../standards/INDEX.md) for the template standards.
